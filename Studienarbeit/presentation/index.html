SDE-basierte Aktienauswahl

Idee

  • Aktienkurse folgen Stochastischer Differentialgleichung (SDE)
  • dS(t) = μS(t)dt + σS(t)dW(t)
  • Modellierung des Einflusses makroökonomischer Faktoren
  • Monte-Carlo-Simulation mit Euler-Maruyama

Makrofaktoren

  • Ölpreis (NYMEX)
  • Goldpreis (COMEX)
  • 10-Jahre-Staatsanleihe
  • S&P 500 Index
  • US-Dollar Index (DXY)
  • 10-Jahre Break-Even-Inflation
SDE-Aktienauswahlverfahren: - Grundidee: Aktienkurse = Trend + Rauschen (stochastisch) - Modellierung: Einfluss von 6 makroökonomischen Faktoren - Für jede Aktie: dominantes Faktorpaar finden - Monte-Carlo-Simulation mit Euler-Maruyama - Aktien mit höchsten simulierten Returns auswählen

Ablauf der SDE-Aktienauswahl

Detaillierter Ablauf: - Schritt 1: Für alle 450 Aktien dominante Faktorpaare bestimmen (OLS-Regression) - Schritt 2: Gruppierung in 4er-Gruppen mit gleichem Faktorpaar - Schritt 3: Kursverlauf über Testzeitraum simulieren - Schritt 4: Beste Aktie pro Gruppe weiter → hierarchischer Prozess - Ergebnis: 10 beste Aktien identifiziert - Vorteile: Skalierbar, vermeidet Selection Bias

Modellkonzeption

3 Modellansätze

    • Zerlegung in Trend, Zyklus, Residuum

  2. Preprocessed SVR

  3. StockTimesFM
    • Foundation Model für Zeitreihen
    • Transfer Learning auf Aktiendaten

  • Test (30%): 07.2024–12.2025
3 Modellansätze: - LinearSeparation: Zerlegung in 3 Komponenten (Trend, Zyklus, Residuum) - SVR: Feature Engineering + Support Vector Regression - TimesFM: Vortrainiertes Foundation Model Datensplit: - 60-10-30 Aufteilung (Training-Validierung-Test) - Testzeitraum: 1,5 Jahre (nie für Training verwendet)

Handelsstrategie

Signalgenerierung

  • Schwellenwert ε basiert auf MAE
  • Kaufsignal: Vorhersage > Aktueller Preis + ε
  • Verkaufssignal: Vorhersage < Aktueller Preis - ε
  • Halten: |Differenz| ≤ ε

Parameter

  • Startkapital: $100.000
  • Position Size: 95% des Kapitals
  • Forecast Horizon: 1 Tag
  • Walk-Forward-Validierung
  • Keine Transaktionskosten
Handelsstrategie - Signalgenerierung: - Schwellenwert ε basiert auf MAE (Validierungsdaten) - Kaufsignal: Vorhersage > Preis + ε → 95% Kapital investieren - Verkaufssignal: Vorhersage < Preis - ε → Cash halten - Walk-Forward-Validierung: Kontinuierliche Modell-Updates Parameter: - $100.000 Startkapital, 1-Tages-Forecast, keine Transaktionskosten

LinearSeparation: Datenfluss

LinearSeparation Datenfluss: - Eingangsdaten: Bereinigung (Splits, Dividenden) - Zerlegung: Trend, Zyklus, Residuum - Training: Separates lineares Modell pro Komponente - Vorhersage: Kombination aller Komponenten - Evaluation: Backtest-Engine mit Metriken - Vorteil: Verschiedene Zeitskalen getrennt modellierbar

Fazit & Ausblick

Zentrale Erkenntnisse

  • ✓ SDE-Aktienauswahl: Innovativ, skalierbar & theoretisch fundiert
  • ✓ Fehlermaße: Gute Punktgenauigkeit (MAPE ~1%)
  • ✓ Beste Methode: Preprocessed SVR übertrifft andere Ansätze
  • ✗ Hauptproblem: Modelle lernen Vortagespreis & Erwartungswert (≈0)
  • ✗ Überglättung: Konservative Vorhersagen, wenig Volatilität
  • ✗ Trading-Gap: Fehlermaße ≠ Trading-Performance
  • ○ Potenzial: Einzelne Aktien profitabel (z.B. AJG: +16,7%)

Ausblick & Verbesserungen

  • Modellierung:
    • Glättungsparameter anpassen/reduzieren
    • Volatilitätsmodellierung einbeziehen
  • Forecast-Strategie:
    • Längere Forecast Horizons (5-10 Tage)
    • Alternative Signalgenerierung testen
    • Adaptive Schwellenwerte
Zusammenfassung: - SDE-Verfahren innovativ & erfolgreich implementiert - Fehlermaße gut, aber fundamentales Problem bei allen Modellen Kernproblem: - Modelle lernen: beste Vorhersage ≈ Vortagespreis - Erwartungswert Renditen ≈ 0 → Überglättung - SVR beste Methode, aber auch unter Buy&Hold Trading-Gap bestätigt: - Gute Punktgenauigkeit garantiert keine Profitabilität Ausblick: - Glättungsparameter reduzieren - Längere Forecast Horizons (5-10 Tage) - Alternative Signalgenerierung entwickeln - Transaktionskosten & Realismus einbeziehen
